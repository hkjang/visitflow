주요 기능

사전 신청부터 체크인, 보안 서약서, 이상 출입 감지 및 AI 연동까지 통합 제공합니다

📋

방문 사전 예약 & 승인

방문자 사전 신청, 접견자(Host) 알림 및 1클릭 승인/반려 프로세스를 제공합니다.

QR 무인 키오스크 체크인

발급된 QR 코드를 키오스크에 스캔하여 셀프 체크인, 출입증 발급 및 체크아웃을 완수합니다.

🚨

이상 출입 & 초과 잔류 감지

미체크아웃 초과 잔류(Overstaying), 미반납 출입증, 블랙리스트 차단을 실시간 관제합니다.

🔐

PII 암호화 & Keycloak OIDC

전화번호/이름 AES-256-GCM 암호화 및 Keycloak OIDC PKCE SSO, Break Glass 비상 계정을 완비했습니다.

🤖

Streamable HTTP MCP Server

Claude Desktop, Cursor 등 AI 에이전트가 호출자의 권한 범위 내에서 안전하게 실시간 방문자 현황을 조회합니다.

📦

오프라인 단일 Docker

Go API 백엔드와 React SPA가 통합된 단일 non-root Docker 이미지로 외부 통신 0% 폐쇄망 배포를 보장합니다.

개발자 API & Streamable MCP

REST API와 Streamable HTTP MCP로 사내 방문자 통합 자동화를 구축하세요

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Archive Load

GitHub Release의 .tar.gz 패키지 하나만 오프라인망으로 반입하여 구동합니다.

docker load < VisitFlow-v1.0.0-linux-amd64-image.tar.gz

# 3개 환경변수로 구동
export POSTGRES_DSN='postgres://visitflow:password@postgres:5432/visitflow'
export BOOTSTRAP_ADMIN='admin'
export BOOTSTRAP_ADMIN_PASSWORD='change-this-strong-password'
docker compose up -d

⚙️ 3대 필수 환경변수

VisitFlow가 사용하는 필수 환경변수는 단 3개입니다.

POSTGRES_DSN=postgres://visitflow:pass@localhost:5432/visitflow
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!

자주 묻는 질문 (FAQ)

네. 외부 CDN, 외부 폰트, 텔레메트리가 전혀 없으며, Go 백엔드, React SPA, QR 코드 생성 엔진이 단일 Docker 이미지로 통합되어 완전 오프라인 구동합니다.

모든 방문자 전화번호 및 개인정보는 AES-256-GCM으로 DB에 암호화되어 보관되며, 화면 및 목록 표기 시 자동으로 마스킹(010-****-1234) 처리됩니다.

네. 예약 종료 시간 경과 후에도 체크아웃되지 않은 방문자, 미반납 출입증, 블랙리스트 방문자를 자동으로 감지하여 관제 대시보드에 실시간 경보를 제공합니다.
