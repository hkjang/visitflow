# VisitFlow 사용자 가이드

## 방문 요청자

1. 방문 신청에서 사업장·시간·목적을 입력한다. 필요하면 매주 2~52회 반복을 설정한다.
2. 방문자를 한 명 이상 추가하고 개인정보 동의를 확인한다. 단체 방문은 CSV/XLSX 첫 시트에서 최대 100명까지 불러올 수 있다.
3. 제출 후 자동 승인 정책이면 즉시, 승인 정책이면 승인 후 방문자별 QR이 발송된다.
4. 내 방문 일정에서 상태, 모바일 방문증, 취소·재발급·재발송을 관리한다.
5. 반복되는 업체와 목적은 방문 템플릿으로 저장하고, 템플릿을 수정하거나 자주 방문자를 연결해 다음 신청에 다시 사용한다.

## 로비 담당자

1. Lobby Dashboard에서 오늘 예정자와 현재 체류 인원을 확인한다.
2. QR Scan에서 카메라, USB Scanner 또는 QR URL 입력으로 검증한다.
3. 방문자·담당자·장소를 확인하고 필요하면 임시 출입증 번호를 입력해 체크인한다.
4. 체크인 즉시 담당자 알림이 발송 대기열에 들어간다.
5. 퇴실 시 현재 방문자 목록에서 퇴실 처리한다.

## 자주 방문자와 템플릿

1. 방문 템플릿 화면의 자주 방문자에서 이름·연락처와 개인정보 동의 여부를 저장한다.
2. 템플릿을 만들거나 수정할 때 필요한 자주 방문자를 선택한다.
3. `이 템플릿으로 신청`을 누르면 최신 자주 방문자 정보가 신청서에 채워진다. 템플릿에는 개인정보 원문 대신 자주 방문자 ID만 연결된다.
4. 더 이상 사용하지 않는 자주 방문자는 직접 삭제할 수 있으며 모든 템플릿 연결도 함께 제거된다. 직접 삭제하지 않아도 마지막 템플릿 사용 후 관리자가 정한 개인정보 파기 기간이 지나면 자동 삭제된다.

## 사용자 가이드 게시판

왼쪽 메뉴의 사용자 가이드에서 관리자가 게시한 최신 운영 안내를 확인한다. 초안 상태의 글은 관리자에게만 보인다.

## 개인 API 키

프로필 → 내 API 키에서 관리자가 허용한 `read`, `write`, `mcp` 범위를 키별로 선택·변경한다. 원문은 생성·회전 직후 한 번만 표시되므로 Password Vault에 보관한다. 주기적으로 회전하고 더 이상 쓰지 않는 키는 즉시 폐기한다.
